# StreamWise

Course project for CS3953 Computer Networks — **Topic 8: Streaming Video Transmission System Design and AI-Driven Adaptive Bitrate**.

StreamWise implements TCP-based segmented video transmission with real-time playback, and explores reinforcement-learning-based adaptive bitrate (ABR) on top of a rule-based baseline.
